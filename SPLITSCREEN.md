# Локальная игра вдвоём

При запуске карты создаются два локальных игрока со своими автомобилями,
камерами и индикаторами. Сейчас экран разделён по вертикали: игрок 1 слева,
игрок 2 справа. Используется автомобиль GameMode текущей карты.

## Выбор геймпадов

1. Подключите два геймпада и запустите игру.
2. Дайте окну игры фокус щелчком мыши.
3. Игрок 1 нажимает A на Xbox или крестик на PS4 на своём геймпаде.
4. Игрок 2 нажимает такую же кнопку на другом геймпаде.

Назначение зависит от порядка присоединения, а не марки геймпада и порядка
подключения к Windows. Подсказки на экране исчезают после присоединения.
Геймпад, который ещё не присоединился, не управляет автомобилями.
Один геймпад не может занять оба места; третий геймпад не влияет на игроков.
F2 на клавиатуре сбрасывает выбор обоих геймпадов: затем присоединитесь заново.
При новом запуске Play выбор также начинается заново.
Клавиатура всегда доступна первому игроку.

Поддерживаются стандартные Xbox/XInput-геймпады и проводной PS4 Sony
VID 054C / PID 09CC, для которого настроен отдельный профиль Raw Input.
Другие модели PlayStation требуют своего профиля; наличие рабочего устройства
в Windows само по себе не означает совместимость со стандартными кнопками Xbox.
Для настроенного PS4 DS4Windows и эмуляция Xbox не требуются.

## Управление

- Левый стик: вверх — газ, вниз — тормоз/задний ход, влево/вправо — руль.
- RT / R2 — газ.
- LT / L2 — тормоз / задний ход.
- LB / L1 — ручной тормоз.
- Правый стик по горизонтали — обзор.
- View / Back / Share — смена камеры.
- Menu / Start / Options — восстановление положения автомобиля.
- A / крестик — присоединение; после присоединения сохраняет действие шаблона.

## Запуск и проверка

В редакторе: Number of Players = 1, Net Mode = Play Standalone.
Второго локального игрока создаёт сам проект. После обновления перезапустите
Unreal Editor, чтобы загрузились новый модуль и настройки устройств.

Source/DronesSetup/LocalMultiplayerSubsystem.* создаёт игроков и автомобили.
LocalMultiplayerViewportClient.* назначает физические геймпады игрокам и
переводит кнопки Sony в стандартные игровые кнопки. Для двух PS4 используется
идентификатор физического устройства из FInputDeviceScope: Raw Input выдаёт
одинаковый логический device/user zero для всех HID-контроллеров.
Config/DefaultInput.ini содержит профиль подключённого PS4.

В VehiclePlayerController инициализация выполняется на On Possess.
Проект содержит C++ модуль: для сборки нужны UE 5.5 и Visual Studio.

Scripts/Test-SplitScreen.ps1 проверяет обе карты без рендеринга: отдельные
автомобили, камеры, HUD, половины экрана и синтетический ввод для сочетаний
Xbox + PS4, PS4 + Xbox, Xbox + Xbox, PS4 + PS4. Также проверяются повторное
нажатие присоединения и игнорирование дополнительных геймпадов.
Физические устройства отключаются только на время автоматического теста.
Сами геймпады и видимость подсказок проверяются вручную в окне игры.

Подробное руководство по кнопкам, новым действиям и отклику стиков: INPUT_GUIDE.md.


Аркадное замедление: Project Settings → Game → Arcade Driving.
